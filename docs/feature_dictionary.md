# Feature dictionary

This describes the 43 features we built for Week 2.

For every history feature below, applicants with no records get 0 for columns ending in `_COUNT` and missing for all other columns. Averages and maximums skip missing values. Averages stay missing if there are no usable values.

The four application ratios do not depend on history records. A zero or missing denominator gives a missing value instead of infinity.

| Feature                    | Source table          | Meaning                                                                             | How it was built                                                                                                                                                                                        |
| -------------------------- | --------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| BUREAU_COUNT               | bureau                | How many credits other lenders reported for the applicant.                          | Count SK_ID_BUREAU records for each SK_ID_CURR.                                                                                                                                                         |
| BUREAU_AMT_CREDIT_SUM_MEAN | bureau                | The average credit amount reported by other lenders.                                | Take the mean of AMT_CREDIT_SUM for each applicant.                                                                                                                                                     |
| BUREAU_AMT_CREDIT_SUM_MAX  | bureau                | The largest credit amount reported by another lender.                               | Take the maximum AMT_CREDIT_SUM for each applicant.                                                                                                                                                     |
| BUREAU_AMT_DEBT_MEAN       | bureau                | The average amount still owed to other lenders.                                     | Take the mean of AMT_CREDIT_SUM_DEBT for each applicant.                                                                                                                                                |
| BUREAU_AMT_OVERDUE_SUM     | bureau                | The total amount overdue with other lenders.                                        | Sum AMT_CREDIT_SUM_OVERDUE for each applicant. For an existing group with all amounts missing, pandas returns 0.                                                                                        |
| BUREAU_DAYS_OVERDUE_MAX    | bureau                | The highest number of days overdue with another lender.                             | Take the maximum CREDIT_DAY_OVERDUE for each applicant.                                                                                                                                                 |
| BUREAU_DAYS_CREDIT_MAX     | bureau                | When the applicant's most recent bureau credit started.                             | Take the maximum DAYS_CREDIT. The value closest to 0 is the most recent.                                                                                                                                |
| BUREAU_ACTIVE_COUNT        | bureau                | How many reported credits are still active.                                         | Count rows where CREDIT_ACTIVE is Active for each applicant.                                                                                                                                            |
| BUREAU_CLOSED_COUNT        | bureau                | How many reported credits are closed.                                               | Count rows where CREDIT_ACTIVE is Closed for each applicant.                                                                                                                                            |
| PREV_COUNT                 | previous_application  | How many earlier applications the person had.                                       | Count SK_ID_PREV records for each applicant.                                                                                                                                                            |
| PREV_APPROVED_RATE         | previous_application  | The share of earlier applications that were approved.                               | Divide the number of rows with NAME_CONTRACT_STATUS equal to Approved by all earlier application rows.                                                                                                  |
| PREV_REFUSED_RATE          | previous_application  | The share of earlier applications that were refused.                                | Divide the number of rows with NAME_CONTRACT_STATUS equal to Refused by all earlier application rows.                                                                                                   |
| PREV_AMT_APPLICATION_MEAN  | previous_application  | The average amount requested on earlier applications.                               | Take the mean of AMT_APPLICATION for each applicant.                                                                                                                                                    |
| PREV_AMT_CREDIT_MEAN       | previous_application  | The average credit amount offered on earlier applications.                          | Take the mean of AMT_CREDIT for each applicant.                                                                                                                                                         |
| PREV_DAYS_DECISION_MAX     | previous_application  | When the most recent earlier application decision happened.                         | Take the maximum DAYS_DECISION for each applicant.                                                                                                                                                      |
| PREV_DAYS_TERMINATION_MEAN | previous_application  | The average termination date of earlier loans, relative to the current application. | Replace the 365243 sentinel with missing, then take the mean of DAYS_TERMINATION.                                                                                                                       |
| PREV_LAST_STATUS           | previous_application  | The status of the most recent earlier application.                                  | Sort by DAYS_DECISION descending, then SK_ID_PREV descending to break ties. Keep the first row per applicant and use NAME_CONTRACT_STATUS.                                                              |
| BB_CREDIT_COUNT            | bureau_balance        | How many bureau credits have monthly history.                                       | Group monthly records by SK_ID_BUREAU, join to bureau to get SK_ID_CURR, then count the credits per applicant.                                                                                          |
| BB_MONTHS_COUNT            | bureau_balance        | How many bureau monthly status records the applicant has.                           | Count nonmissing STATUS values per bureau credit, then sum those counts per applicant.                                                                                                                  |
| BB_LATE_MONTHS_COUNT       | bureau_balance        | How many bureau months were marked late.                                            | Convert STATUS to numbers and count values 1 through 5 per credit, then sum per applicant. C and X become missing and are not counted as late.                                                          |
| BB_LATE_SHARE              | bureau_balance        | The share of bureau monthly records marked late.                                    | Divide BB_LATE_MONTHS_COUNT by BB_MONTHS_COUNT using the applicant's totals.                                                                                                                            |
| BB_WORST_STATUS            | bureau_balance        | The worst numeric bureau status in the monthly history.                             | Convert STATUS to numbers and take the maximum across the applicant's credits. C and X are ignored. Missing if there are no numeric statuses.                                                           |
| POS_LOAN_COUNT             | POS_CASH_balance      | How many different earlier POS or cash loans the applicant has.                     | Count distinct SK_ID_PREV values per applicant.                                                                                                                                                         |
| POS_MONTHS_COUNT           | POS_CASH_balance      | How many monthly POS or cash loan records the applicant has.                        | Count SK_ID_PREV records per applicant, including repeated loans across months.                                                                                                                         |
| POS_DPD_MAX                | POS_CASH_balance      | The most days past due in the POS or cash loan history.                             | Take the maximum SK_DPD per applicant.                                                                                                                                                                  |
| POS_DPD_MEAN               | POS_CASH_balance      | The average days past due across POS or cash loan records.                          | Take the mean of SK_DPD per applicant.                                                                                                                                                                  |
| POS_LATE_SHARE             | POS_CASH_balance      | The share of monthly POS or cash loan records that were late.                       | Divide the number of rows where SK_DPD is above 0 by all monthly rows for the applicant.                                                                                                                |
| POS_COMPLETED_SHARE        | POS_CASH_balance      | The share of earlier POS or cash loans that were recorded as completed.             | For each loan, check whether any NAME_CONTRACT_STATUS is Completed. Average those indicators across the applicant's loans.                                                                              |
| INST_COUNT                 | installments_payments | How many installment payment records the applicant has.                             | Count SK_ID_PREV records per applicant. Rows without a recorded payment still count.                                                                                                                    |
| INST_LATE_SHARE            | installments_payments | The share of recorded payments made after the due date.                             | Compare DAYS_ENTRY_PAYMENT with DAYS_INSTALMENT and average the late indicators per applicant. Rows with missing DAYS_ENTRY_PAYMENT are excluded.                                                       |
| INST_DAYS_LATE_MAX         | installments_payments | The most days an installment payment was late.                                      | Subtract DAYS_INSTALMENT from DAYS_ENTRY_PAYMENT, clip negative differences to 0, and take the maximum per applicant. Missing payment dates are ignored. An existing group with no usable dates gets 0. |
| INST_UNDERPAID_SHARE       | installments_payments | The share of recorded payments that were less than the amount due.                  | Compare AMT_PAYMENT with AMT_INSTALMENT and average the underpayment indicators per applicant. Rows with missing AMT_PAYMENT are excluded.                                                              |
| INST_PAYMENT_DIFF_MEAN     | installments_payments | The average difference between what was paid and what was due.                      | Take the mean of AMT_PAYMENT minus AMT_INSTALMENT per applicant. Missing differences are skipped. A negative result means less was paid than was due on average.                                        |
| CC_MONTHS_COUNT            | credit_card_balance   | How many credit card monthly records the applicant has.                             | Count nonmissing MONTHS_BALANCE values per applicant. Each card-month record counts separately.                                                                                                         |
| CC_BALANCE_MEAN            | credit_card_balance   | The average credit card balance.                                                    | Take the mean of AMT_BALANCE per applicant. Negative balances are kept because they can represent overpayments.                                                                                         |
| CC_UTILIZATION_MEAN        | credit_card_balance   | The average balance compared to the credit limit.                                   | Use safe_divide on AMT_BALANCE and AMT_CREDIT_LIMIT_ACTUAL for each row, then take the mean per applicant. Zero or missing limits give missing utilization.                                             |
| CC_UTILIZATION_MAX         | credit_card_balance   | The highest balance compared to the credit limit.                                   | Use safe_divide on AMT_BALANCE and AMT_CREDIT_LIMIT_ACTUAL for each row, then take the maximum per applicant. Missing utilization is skipped.                                                           |
| CC_DRAWINGS_MEAN           | credit_card_balance   | The average amount drawn from the credit card in a monthly record.                  | Take the mean of AMT_DRAWINGS_CURRENT per applicant.                                                                                                                                                    |
| CC_DPD_MAX                 | credit_card_balance   | The most days past due in the credit card history.                                  | Take the maximum SK_DPD per applicant.                                                                                                                                                                  |
| CREDIT_INCOME_RATIO        | application_train     | The credit amount compared to the applicant's income.                               | Use safe_divide to calculate AMT_CREDIT / AMT_INCOME_TOTAL.                                                                                                                                             |
| ANNUITY_INCOME_RATIO       | application_train     | The loan annuity compared to the applicant's income.                                | Use safe_divide to calculate AMT_ANNUITY / AMT_INCOME_TOTAL. A missing annuity also gives a missing result.                                                                                             |
| CREDIT_GOODS_RATIO         | application_train     | The credit amount compared to the price of the goods.                               | Use safe_divide to calculate AMT_CREDIT / AMT_GOODS_PRICE.                                                                                                                                              |
| ANNUITY_CREDIT_RATIO       | application_train     | The loan annuity compared to the total credit amount.                               | Use safe_divide to calculate AMT_ANNUITY / AMT_CREDIT. A missing annuity also gives a missing result.                                                                                                   |
